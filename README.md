# Vehicle Dealership Reviews Capstone Project

This project is a full stack vehicle dealership review application developed as part of the Full Stack Developer Capstone.

## Features

- User registration and authentication
- View dealerships
- View dealer reviews
- Add reviews
- Car Make and Car Model management
- Django backend
- React frontend
- MongoDB and SQLite databases

## Technologies Used

- Django
- React
- Python
- JavaScript
- MongoDB
- SQLite
- Docker
